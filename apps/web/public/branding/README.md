# Logo del cliente

Coloca aquí los archivos originales del logo de la empresa.

- `logo.svg`: preferido para el logo vectorial; también puedes usar `logo.png` con fondo transparente y buena resolución.
- `favicon.ico` o `favicon.svg`: si ya tienes una versión para la pestaña del navegador.
- `icon-192.png` e `icon-512.png`: si ya tienes los iconos de la aplicación instalada.

No es necesario que prepares todos los formatos: puedes empezar colocando solamente el logo original.

Los archivos de esta carpeta se publican bajo `/branding/` al desplegar la web.

El favicon y los iconos actuales se conservan hasta que se agregue el logo y se conecten sus versiones al HTML y al manifiesto de la aplicación.
